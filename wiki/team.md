# The team

FaceHugger was built by six Computer Science students at EPFL for the *Making Intelligent Things* course (2026 spring). Over eight weeks, with weekly SCRUM meetings and steady week-to-week work, we split the robot across CAD, manufacturing, electronics, firmware, a control app, and a simulation and animation pipeline, then brought it together into one walking robot.

## How we worked

We ran the project as weekly SCRUM sprints: each week we reviewed progress, replanned, and divided the next set of tasks. Because the robot spans so many disciplines, most work happened in parallel (CAD and printing feeding assembly, firmware and the app developing against a shared command protocol, and the simulation validating motion before it reached hardware), with the weekly sync keeping the interfaces between those pieces aligned.
